# Sync Lyrics
Prerequisties
  - Musixmatch
  - NodeJS
  - Spotify Premium
 
1. Download Musixmatch (https://about.musixmatch.com/apps) and NodeJS

2. Connect Spotify to Musixmatch account

3. Play any song on Spotify (it will automatically play it on Musixmatch)

4. Copy and paste lyrics and timestamps from Musixmatch into a new .txt file in the Songs folder

5. In sync.js, change the variable songName to the name of the file where you copy and pasted your lyrics

6. Run sync.js in terminal (node sync.js)

7. Enjoy!
